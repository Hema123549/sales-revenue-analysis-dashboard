# Sales & Revenue Analysis Dashboard

## 📊 Project Overview

This project is an interactive Sales & Revenue Analysis Dashboard developed using Microsoft Power BI. The dashboard provides a clear view of sales and profit performance across different categories, regions, and orders.

The project helps users analyze business performance and identify sales and profit trends through interactive visualizations.

## 🎯 Objectives

- Analyze overall sales and profit performance
- Compare sales across different product categories
- Analyze profit trends over time
- Compare sales across different orders
- Provide interactive filtering using category and region
- Present business insights through an interactive dashboard

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Microsoft Excel
- Data Visualization
- Data Analysis

## 📁 Dataset

The dataset contains sales-related information used to build the dashboard.

Key fields include:

- Order ID
- Date
- Product
- Category
- Region
- Sales
- Quantity
- Profit

The dataset is available in this repository as:

`sales_data.xlsx`

## 📈 Dashboard Features

- Interactive Sales Dashboard
- Category-wise sales analysis
- Profit trend analysis
- Order-wise sales comparison
- Region filters
- Category filters
- Interactive charts and visualizations

## 💡 Key Insights

The dashboard can be used to identify:

- Sales contribution from different categories
- Profit trends across different dates
- High-performing orders
- Regional sales performance
- Differences in sales between product categories
